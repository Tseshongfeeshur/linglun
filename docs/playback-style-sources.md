# 播放页样式参考来源

第一种播放页参考了 AMLL 的横向/竖向自适应布局、逐词时间渐变、活动歌词居中滚动、封面环境背景和进度控制行为：

- 项目：applemusic-like-lyrics（AMLL）
- 来源：`https://github.com/amll-dev/applemusic-like-lyrics`
- 本地参考版本：`@applemusic-like-lyrics/core` 0.6.0
- 上游许可证：AGPL-3.0-only，许可证全文位于用户提供的 `TEMP/applemusic-like-lyrics/LICENSE`
- 使用范围：仅将组件结构、视觉效果和交互行为作为实现参考；伶伦实现使用 Flutter/Dart 重写，没有复制上游代码、样式表或图片资源，也没有新增 AMLL 运行时依赖。

伶伦保留本地播放产品约束，因此没有加入 AirPlay 和独立音量控制。页面中的播放、暂停、切歌、随机、循环、定位、歌词显示和播放队列均接入伶伦自身状态。

歌词视图按该版本的样式参数实现左对齐主歌词、当前配置的 450 字重、活动行聚焦和逐词渐变遮罩；桌面字号按 `max(max(5vh, 2.5vw), 12px)` 计算，窄视口按 `max(8vw, 12px)` 计算，翻译采用正文 `4/5` 字号、30% 透明度和 1.5 倍行高，背景/对唱声部采用 70% 字号和 40% 透明度。歌词行顶部及水平内边距均为 `0.4em`，底部在此基础上额外增加 4px，副行之间保持 `0.3em` 间距，字距为 `0.1`。列表滚动条隐藏；歌词行悬停时显示 `#fff1` 级别的圆角背景。焦点行以 97% 缩放并按约 45ms 累计错峰，列表使用 FLIP 保留旧画面位置后归位；活动行的延迟归零，上方行允许约 36ms 的预滚动，使焦点切换和滚动从同一时刻开始。缩放不使用位图重采样，逐词移动沿用整句固定字形度量；逐词羽化遮罩同时作用于强调字符和辉光，避免清晰字形覆盖进度渐变。焦点对齐位置按用户要求设为列表高度的三分之一，而非 AMLL 播放器配置示例中的 0.35。

逐字歌词根据同一套整句字形度量裁切显示，避免动画期间改变排版而抖动；已排版的 `TextPainter`、逐词边界和逐字边界会在文本、排版属性或绘制宽度变化时才重建，播放帧只更新 Canvas 绘制状态，并以局部 `RepaintBoundary` 隔离重绘，透明 `Text` 仍提供原有的布局尺寸。单词按约 `0.07em` 轻微上浮，持续至少一秒且满足 AMLL 词长规则时增加逐字符辉光，并采用上游的双段缓动节奏、字符缩放、横向推挤和正弦上浮。逐词高亮使用宽度为实际字框高度 `0.5` 倍的移动渐变遮罩，遮罩的有效移动距离为单词宽度加一个羽化宽度，使每个单词完成时羽化边缘自然越过字符边界，而不是留下末端残影或发生完成态突变；辉光保存层保持原有字符级合成边界，清晰高亮与模糊光晕分层合成，避免清除原字符时影响相邻字符。强调字符的正弦上浮幅度为普通字符的 `0.07em`，背景声部为 `0.13em`，字符变形上浮幅度为 `0.03em`。歌词行高测量与实际绘制共享系统文字缩放、粗体辅助设置、字距、语言环境和行高行为，另加 2px 舍入余量，避免长主歌词和译文换行后溢出。七秒及以上的歌词间隔显示三点等待动画，鼠标悬停歌词区域会缓动清除远处歌词的模糊。专辑封面在播放和暂停时保持相同尺寸；普通 Flutter 文本和歌词 TextPainter 均使用 MiSans。TTML 背景声部保留自己的行/字时间和说话者信息，再作为主歌词组的背景行渲染。

Flutter 与浏览器的字体度量、滤镜合成和逐帧调度不同，仍需真实 Linux 窗口截图及实际音乐播放继续校准，不能视为逐像素一致。
