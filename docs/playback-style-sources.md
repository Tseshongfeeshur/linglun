# 播放页样式参考来源

第一种播放页参考了 AMLL 的横向/竖向自适应布局、逐词时间渐变、活动歌词居中滚动、封面环境背景和进度控制行为：

- 项目：applemusic-like-lyrics（AMLL）
- 来源：`https://github.com/amll-dev/applemusic-like-lyrics`
- 本地参考版本：`@applemusic-like-lyrics/react-full` 0.5.0
- 上游许可证：AGPL-3.0-only，许可证全文位于用户提供的 `TEMP/applemusic-like-lyrics/LICENSE`
- 使用范围：仅将组件结构、视觉效果和交互行为作为实现参考；伶伦实现使用 Flutter/Dart 重写，没有复制上游代码、样式表或图片资源，也没有新增 AMLL 运行时依赖。

伶伦保留本地播放产品约束，因此没有加入 AirPlay 和独立音量控制。页面中的播放、暂停、切歌、随机、循环、定位、歌词显示和播放队列均接入伶伦自身状态。

歌词视图按该版本的样式参数实现左对齐主歌词、600 字重、活动行聚焦和逐词渐变遮罩；默认字号按 `max(5vh, 14px)` 计算，翻译采用半字号、30% 透明度和 1.5 倍行高，背景/对唱声部采用 70% 字号和 40% 透明度。为回应实际观感，伶伦将歌词组上下留白设为 `0.55em`（AMLL 为 `0.4em`），副行之间保持 `0.3em` 间距，并将词间距设为 2.5 逻辑像素。焦点行以 97% 缩放并按约 50ms 阶梯交错平移；缩放不使用位图重采样，逐词移动沿用整句固定字形度量。焦点对齐位置按用户要求设为列表高度的三分之一，而非 AMLL 播放器配置示例中的 0.35。

逐字歌词根据同一套整句字形度量裁切显示，避免动画期间改变排版而抖动；单词按约 `0.05em` 轻微上浮，持续至少一秒且满足 AMLL 词长规则时增加逐字符辉光，并采用上游的双段缓动节奏。七秒及以上的歌词间隔显示三点等待动画，鼠标悬停歌词区域会缓动清除远处歌词的模糊。专辑封面播放时为完整尺寸，暂停时以 75% 比例收缩并使用 AMLL 风格缓动恢复。TTML 背景声部保留自己的行/字时间和说话者信息，再作为主歌词组的背景行渲染。

Flutter 与浏览器的字体度量、滤镜合成和逐帧调度不同，仍需真实 Linux 窗口截图及实际音乐播放继续校准，不能视为逐像素一致。
