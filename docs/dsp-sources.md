# DSP 来源记录

## 当前版本

当前版本没有复制第三方 DSP 项目的算法代码。基础播放和基础音频处理通过
`media_kit` 调用本机 `libmpv`，滤镜图由伶伦根据设置模型生成，再交给
`libavfilter` 执行。

当前使用的处理包括 ReplayGain、参数化 EQ、Bass 基础增强、Crossfeed 和输出限幅。
这些处理的参数和调用方式属于播放后端配置，不是从第三方项目复制的源码。

## 后续引入规则

如果后续引入 bs2b、SOFA/HRTF、动态 Bass 或其他开源实现，必须在此文件记录：

- 项目名称、版本和固定提交；
- 上游许可证及其与本项目许可证的兼容性；
- 使用的算法或文件范围；
- 伶伦自行修改的内容；
- 构建、运行时和音频数据依赖。

在许可证和音质验证完成前，不直接复制第三方源码，也不把未经验证的近似实现标记为
高质量 DSP。
