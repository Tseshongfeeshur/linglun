# 伶伦

> *昔黄帝令伶伦作为律。*
>
> *伶伦自大夏之西，乃之阮隃之阴，取竹于嶰谿之谷，以生空窍厚钧者、断两节间、其长三寸九分而吹之，以为黄钟之宫，吹曰‘舍少’。次制十二筒，以之阮隃之下，听凤皇之鸣，以别十二律。其雄鸣为六，雌鸣亦六，以比黄钟之宫，适合。黄钟之宫，皆可以生之，故曰黄钟之宫，律吕之本。*
>
> *黄帝又命伶伦与荣将铸十二钟，以和五音，以施英韶，以仲春之月，乙卯之日，日在奎，始奏之，命之曰咸池。*
>
> <p align="right">——《吕氏春秋》</p>

相传，黄帝乐官伶伦截竹为管，定十二律。

如今，伶伦让乐曲完全属于你。

伶伦是一个用 Flutter 编写的**本地音乐播放器**，致力于提供流畅的操作和播放体验、美观的用户界面、完善的歌曲管理和精细的 DSP 处理。

> 项目处于**早期开发阶段**：曲库管理已经可用，播放、歌词与 DSP 尚在开发中。
>
> 本项目有**至少 4 年的长期维护计划**；开发过程中极少使用 AI，AIGC 代码不超过 5%。

---

## 特性

### 曲库管理

- **增量扫描**：只重新读取新增或被修改的文件，大曲库的刷新更快；重新扫描不会丢失播放次数和添加时间
- **大文件友好**：几百 MB 的无损文件也能正常读取标签
- **多语言支持**：支持拉丁（汉语拼音）、假名、谚文、西里尔文字的分组和排序
- **最小权限（Android）**：遵循最小权限原则，仅读写被授权的目录

### 播放

- **自研播放引擎**：让每一段声波和采样都可以轻松控制

### 界面

- **响应式设计**：使用 Material 响应式断点，令布局自适应
